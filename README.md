# 🪔 हिंदी ज्ञानदीप (Hindi GyanDeep) - अक्षर से अखबार पढ़ना सीखें

विशेष रूप से उन बड़ों और नए पाठकों के लिए बनाया गया एक सरल, सुंदर और पूर्णतः हिंदी वेब-गेम (PWA), जो हिंदी पढ़ना सीखकर अखबार (जैसे दैनिक भास्कर, अमर उजाला) और पुस्तकें आसानी से पढ़ना चाहते हैं।

---

## 🌟 मुख्य विशेषताएँ (Key Features)

1. **१००% शुद्ध और सरल हिंदी इंटरफ़ेस**:
   - कोई भी अंग्रेज़ी शब्द या भ्रामक मेनू नहीं। बड़े, स्पष्ट देवनागरी अक्षर और आसान टच बटन।
2. **'ल', 'र', 'य' का विशेष अभ्यास**:
   - इन तीन अक्षरों के भ्रम को दूर करने के लिए विशेष रूप से डिज़ाइन किए गए प्रश्न और तुलनात्मक विकल्प (*जल/जर/जय*, *कलम/करम*, *सरल/समय*, *महल/नहर*, *राजा/लाया*, *रात/याद*)।
3. **मात्राओं का सहज व व्यावहारिक अभ्यास**:
   - भ्रमित करने वाले अनावश्यक मात्रा-जालों को हटाकर अखबार पढ़ने के व्यावहारिक आत्मविश्वास पर जोर।
4. **१०५ क्रमबद्ध स्तर (105 Progressive Levels)**:
   - **चरण १ (स्तर १-१५)**: २-३ अक्षर के सरल शब्द व 'ा' मात्रा + ल, र, य अभ्यास।
   - **चरण २ (स्तर १६-३०)**: दैनिक जीवन की सभी मात्राएँ (पानी, रोटी, दूध, मंदिर, बाज़ार, दुकान)।
   - **चरण ३ (स्तर ३१-५०)**: आधे अक्षर और संयुक्त वर्ण (क्या, स्कूल, दोस्त, दिल्ली, डॉक्टर, व्यापार, ट्रेन)।
   - **चरण ४ (स्तर ५१-७०)**: रोज़मर्रा के वाक्य व सामाजिक/सरकारी शब्दावली (सरकार, अस्पताल, पुलिस, मौसम, बैंक)।
   - **चरण ५ (स्तर ७१-९०)**: अखबार की सुर्खियाँ (Headlines) व वाक्य निर्माण (Sentence Builder)।
   - **चरण ६ (स्तर ९१-१०५+)**: पूरे समाचार पैराग्राफ, प्रेरक कहानियाँ व "अखबार मास्टर" प्रमाण पत्र।
5. **अखबार कॉर्नर (Newspaper Reading Room)**:
   - असली अखबार जैसा दिखने वाला सेक्शन जहाँ देश, खेती, मौसम, सेहत, और धर्म के समाचार उपलब्ध हैं।
   - **किसी भी शब्द को छूने पर वह आवाज़ में बोलकर सुनाएगा!**
6. **हिंदी आवाज़ (Text-to-Speech) व साउंड इफ़ेक्ट्स**:
   - Web Speech API से स्पष्ट हिंदी उच्चारण।
   - सामान्य गति (1.0x) और धीमी आवाज़ (0.65x) का बटन।
   - मधुर घंटियाँ, उत्साहवर्धक शाबाशी और सितारे।
7. **बिना इंटरनेट चलने की क्षमता (100% Offline PWA)**:
   - सर्विस वर्कर और मैनिफेस्ट के साथ, फ़ोन में एक बार इंस्टॉल होने के बाद बिना इंटरनेट भी चलेगा।

## 📲 गिटहब (GitHub Pages) पर अपलोड करने की विधि

आप इसे गिटहब पर बिल्कुल मुफ्त में होस्ट कर सकते हैं ताकि यह किसी भी फ़ोन के क्रोम में खुल सके:

### कदम १: नया गिटहब रिपॉजिटरी बनाएं
1. [GitHub.com](https://github.com/) पर जाएं और नया रिपॉजिटरी बनाएं (जैसे: `hindi-gyandeep`).
2. इसे **Public** रखें।

### कदम २: कोड अपलोड करें
अपने कंप्यूटर के टर्मिनल (PowerShell / Command Prompt) में इस फोल्डर में निम्न कमांड चलाएं:

```bash
git init
git add .
git commit -m "हिंदी ज्ञानदीप - प्रथम संस्करण"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/hindi-gyandeep.git
git push -u origin main
```
*(नोट: `YOUR_USERNAME` की जगह अपना गिटहब यूज़रनेम लिखें)*

### कदम ३: GitHub Pages चालू करें
1. गिटहब रिपॉजिटरी के **Settings** टैब में जाएं।
2. बायीं तरफ **Pages** पर क्लिक करें।
3. **Branch** में `main` चुनें और **Save** पर क्लिक करें।
4. 1-2 मिनट में आपकी वेबसाइट का लिंक तैयार हो जाएगा (जैसे: `https://YOUR_USERNAME.github.io/hindi-gyandeep/`)।

## 📱 फ़ोन में ऐप की तरह इंस्टॉल करने की विधि (Android Chrome)

1. अपने पिताजी के एंड्रॉइड फ़ोन में **Google Chrome** खोलें।
2. अपना GitHub Pages वाला लिंक खोलें।
3. स्क्रीन पर नीचे **"📲 फ़ोन में इनस्टॉल करें"** का बटन दिखेगा, उस पर क्लिक करें।
   - अथवा क्रोम के ऊपर दाईं ओर **तीन बिंदुओं (⋮)** पर टैप करें।
   - **"Install app"** या **"Add to Home screen" (होम स्क्रीन में जोड़ें)** चुनें।
4. ऐप का सुंदर आइकन (दीपक और किताब) फोन के होम स्क्रीन पर आ जाएगा।
5. अब वे इसे जब चाहें बिना इंटरनेट के भी असली ऐप की तरह खोलकर खेल सकते हैं!
